1. WHAT WE ARE BUILDING
Project: ASQAC – Adaptive Specimen Quality Assurance Capsule Product name for the web app: ASQAC · Capsule Care Connect

Problem: In hospitals, many lab errors happen before the specimen reaches the lab (the pre-analytical phase). Barcode/RFID only tell where a specimen is, not how it was handled. Excess temperature, drops/shocks, wrong orientation, light exposure, lid opening and long transport times can silently ruin a specimen, causing wrong diagnoses and repeat collections.

Solution: A reusable smart capsule that carries specimen tubes between wards and labs. An ESP32-C3 inside reads sensors continuously and sends the data over hospital Wi-Fi to the cloud. A web app lets staff:

Register a specimen and bind it to a capsule (QR based).
Load a specimen-specific handling profile (limits depend on specimen type).
Watch the transport live with sensor widgets.
Get alerts the moment a limit is broken.
At the lab, the receiving doctor ends the transport, reviews the full handling history and gives a final verdict: Accept / Review Required / Reject.
Keep a full chain-of-custody audit trail for reports.
The capsule mechanically also has a motor-driven test-tube rotation system and a planned MR-damper vibration isolation (future work) – show these only as an informational "Capsule hardware" / roadmap section, not as live data.

3. REAL HARDWARE (only these sensors – never invent others)
Part	Interface	Data
ESP32-C3 Super Mini	Wi-Fi, I²C SDA = GPIO9, SCL = GPIO8, 4.7 kΩ pull-ups	controller

5. HOW DATA FLOWS (design this properly)
ESP32 reads the 3 sensors → builds JSON (device id, timestamp, temp, pressure, lux, accel x/y/z, pitch, roll, shock peak, wifi rssi).
ESP32 sends HTTPS POST to a Supabase Edge Function with a per-device secret token in a header. The ESP32 never holds Supabase admin keys.
Edge Function: verifies the device token (store only a hash), validates the payload, finds the capsule's active transport and its handling profile, stores the reading, compares against limits, creates alerts for breaches, updates capsule "last seen".
Website subscribes to Realtime → widgets, charts and alerts update live without refresh.
Lost connection: if an in-transit capsule hasn't reported for > 2 min, raise a connectivity alert.
Stay inside free-tier limits (reasonable sampling, prune or downsample old readings).

Audit trail: every registration, transport start/end, alert, acknowledgement and verdict logged with actor and time; shown as chain of custody.
